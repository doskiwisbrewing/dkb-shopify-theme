# Blog Styling Guidelines

### How to Use Custom Layout Blocks in Shopify Articles

This guide explains how to use our custom layout classes when editing
blog posts in Shopify.

You **do not need to know HTML** --- just copy and paste the examples
below and replace the content.

------------------------------------------------------------------------

# 1. Creating or Modifying a Blog Post in Shopify

## To Create a New Blog Post

1.  Go to **Online Store → Blog Posts**
2.  Click **Add Blog Post**
3.  Add your title and write your content using the normal visual editor
    first
4.  Add images using the image button (see image instructions below)
5.  Once the content structure is ready, switch to **HTML view** (\<\>
    button)
6.  Add the layout blocks where needed
7.  Preview before publishing

------------------------------------------------------------------------

## To Modify an Existing Blog Post

1.  Go to **Online Store → Blog Posts**
2.  Click on the blog post you want to edit
3.  Make your changes in the normal visual editor first (text, headings,
    images)
4.  When layout adjustments are needed, click the **\<\> (Show HTML)**
    button
5.  Insert or adjust the layout block structure
6.  Save and preview

⚠️ Always be careful not to delete closing `</div>` tags.

------------------------------------------------------------------------

# 2. How to Add Images from Shopify

The recommended workflow is:

1.  Use the **normal visual editor first**
2.  Click the **Insert Image** button
3.  Upload the image or select it from existing files
4.  Insert it into the content
5.  Switch to **HTML view**
6.  Move the `<img>` element inside the layout block you need

Example of an inserted image in HTML:

``` html
<img src="https://cdn.shopify.com/your-image.jpg" alt="Description">
```

You do not need to manually paste image URLs unless necessary ---
Shopify generates them automatically.

------------------------------------------------------------------------

# 3. Full Width Image (100% Screen Width)

Use this when you want an image to take the entire width of the screen.

## Example

``` html
<div class="article-template--full-size">
  <img src="IMAGE-URL-HERE.jpg" alt="">
</div>
```

Replace `IMAGE-URL-HERE.jpg` with your image URL (usually already
generated by Shopify).

------------------------------------------------------------------------

# 4. Two Column Layout

Use this to create content in two vertical columns.

You can use:
- Text + Image
- Image + Text
- Image + Image
- Text + Text

## Two Images Side by Side

``` html
<div class="article-template-block-2-col">
  <p><img src="IMAGE-1.jpg" alt=""></p>
  <p><img src="IMAGE-2.jpg" alt=""></p>
</div>
```

## Text Left -- Image Right

``` html
<div class="article-template-block-2-col">
  <div>
    <h3>Title</h3>
    <p>Your text goes here.</p>
  </div>
  <p><img src="IMAGE.jpg" alt=""></p>
</div>
```

## Image Left -- Text Right

``` html
<div class="article-template-block-2-col">
  <p><img src="IMAGE.jpg" alt=""></p>
  <div>
    <h3>Title</h3>
    <p>Your text goes here.</p>
  </div>
</div>
```

------------------------------------------------------------------------

# 5. Three Column Grid

Use this for:
- 3 images in a row
- 3 content blocks
- Gallery sections

## Three Images Example

``` html
<div class="article-template-block-3-col">
  <p><img src="IMAGE-1.jpg" alt=""></p>
  <p><img src="IMAGE-2.jpg" alt=""></p>
  <p><img src="IMAGE-3.jpg" alt=""></p>
</div>
```

## Three Text Blocks Example

``` html
<div class="article-template-block-3-col">
  <div>
    <h3>Title 1</h3>
    <p>Text here.</p>
  </div>
  <div>
    <h3>Title 2</h3>
    <p>Text here.</p>
  </div>
  <div>
    <h3>Title 3</h3>
    <p>Text here.</p>
  </div>
</div>
```

------------------------------------------------------------------------

# 6. Centered Content (Normal Reading Width)

Use this to keep text readable and centered.

``` html
<div class="page-width">
  <h2>Your section title</h2>
  <p>Your paragraph text goes here.</p>
</div>
```

------------------------------------------------------------------------

# 7. Block Quote / Highlight Text

Use this to highlight important paragraphs.

``` html
<div class="article-template-block-quote">
  <p>Your highlighted text goes here.</p>
</div>
```

------------------------------------------------------------------------

# 8. Good Workflow

✅ Write content first in the visual editor\
✅ Upload and place images normally\
✅ Switch to HTML only when adjusting layout\
✅ Keep layout blocks clean and simple\
✅ Always preview before publishing

------------------------------------------------------------------------

# 9. Things to Avoid

❌ Do not nest column blocks inside other column blocks\
❌ Do not add extra empty `<p>` tags\
❌ Do not forget to close `</div>`
